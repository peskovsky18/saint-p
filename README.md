# Санкт-Петербург в изометрии (SPb-Izo)

> **Интерактивная изометрическая пиксельная 3D-карта Санкт-Петербурга в реальном времени на открытых данных.**  
> Вдохновлено проектом [Isometric Warsaw (Warsaw-izo)](https://bedirhanyildirim.com/warsaw-izo/) Бедирхана Йылдырыма.

![SPb-Izo Banner](public/favicon.svg)

## 🌟 Возможности проекта

1. **Изометрическая пиксельная эстетика:**
   - Камера с истинным изометрическим углом (`OrthographicCamera`, угол наклона $\approx 35.264^\circ$, повороты на $90^\circ$).
   - Пиксельный рендеринг (quantized rendering buffer) в духе классических градостроительных симуляторов (SimCity 2000).
   - Аутентичная архитектурная палитра Санкт-Петербурга: бирюзовый Зимний дворец, желтый ампир Главного штаба и Адмиралтейства, серый гранит набережных, терракота, оливковые доходные дома, жестяные крыши и золотые шпили.

2. **Культовые достопримечательности:**
   - **Зимний дворец (Эрмитаж)** с Большим парадным двором и статуями на парапетах.
   - **Дворцовая площадь и Главный штаб** с Триумфальной аркой Росси и Колесницей Славы.
   - **Александровская колонна** — монолит из красного гранита с Ангелом на вершине.
   - **Адмиралтейство** со знаменитым 72-метровым золотым шпилем и корабликом.
   - **Исаакиевский собор** с колоннадами из цельного гранита, 4 колокольнями и позолоченным гигантским куполом (высота 101.5 м).
   - **Петропавловская крепость** на Заячьем острове с золотым шпилем собора (122.5 м) и летящим ангелом.
   - **Стрелка Васильевского острова** с двумя Ростральными колоннами и зданием Биржи.
   - **Спас на Крови** с разноцветными эмалированными куполами на канале Грибоедова.
   - **Доходные дома с дворами-колодцами** и парки (Летний сад, Марсово поле).

3. **Разводные мосты (главная фишка Петербурга!):**
   - **Дворцовый мост** — двукрылый разводной мост, открывающий вид на стрелку и шпиль Петропавловки.
   - **Троицкий мост** — однокрылый подъемный пролет со стороны Суворовской площади.
   - **Благовещенский и Биржевой мосты**.
   - Анимация разводки по кнопке или автоматическое открытие по реальному ночному расписанию (01:10 – 04:55).

4. **Солнце и Белые ночи (SunCalc):**
   - Расчёт астрономического положения солнца по координатам СПб (`59.9398° N, 30.3146° E`).
   - Реалистичные динамические тени, меняющие длину и угол в течение дня.
   - Режим **Белых ночей**: в июне солнце опускается лишь на несколько градусов ниже горизонта — небо окрашивается в нежные сиреневые и золотые тона, и темнота не наступает.
   - Интерактивный ползунок времени суток (00:00 — 24:00) + режим реального времени.

5. **Живой общественный транспорт:**
   - **Трамваи** (классические красно-белые вагоны ЛМ-68М) на маршруте №3 через Троицкий мост и Садовую улицу.
   - **Скоростные «Метеоры»** на подводных крыльях, мчащиеся по фарватеру Невы с пенным следом.
   - Прогулочные теплоходы и ночные сухогрузы.

6. **Погода онлайн (Open-Meteo API):**
   - Получение текущей температуры, осадков, облачности и скорости ветра в СПб в реальном времени.
   - Пиксельный дождь (знаменитый петербургский ливень и морось), снег и туман над Невой.

7. **Уровень воды в Неве (Ординар):**
   - Моделирование гидрологического уровня (по гидропосту «Горный институт»): норма, нагонная волна (+60 см), порог наводнения (+160 см с предупреждением).

8. **Симулятор полёта (Flight Simulator ✈️):**
   - Управление бипланом над крышами Санкт-Петербурга.
   - Управление: `W`/`S` — тангаж (вверх/вниз), `A`/`D` — крен/поворот, `Shift`/`Ctrl` — тяга двигателя.
   - Камера плавно следует за самолётом, позволяя пролетать между разведенными крыльями Дворцового моста и вокруг шпиля Петропавловки!

## 🚀 Запуск проекта

Убедитесь, что установлены Node.js (>= 18):

```bash
# Установка зависимостей (уже выполнены в проекте)
npm install

# Запуск локального сервера разработки
npm run dev
```

После этого откройте в браузере адрес: `http://localhost:5173`.

Сборка для продакшена:
```bash
npm run build
npm run preview
```

## 📁 Структура проекта

```text
├── index.html            # Точка входа HTML (с метатегами для мобильных устройств)
├── src/
│   ├── main.ts           # Главный цикл приложения и инициализация Three.js
│   ├── camera.ts         # Изометрическая камера (Orthographic) и управление
│   ├── palette.ts        # Аутентичная питерская архитектурная палитра
│   ├── geo.ts            # Проекция координат WGS84 в метры мира (центр — Дворцовая пл.)
│   ├── sun.ts            # Астрономическое солнце, Белые ночи, свет и тени (SunCalc)
│   ├── water.ts          # Шейдер воды Невы, волны, уровень ординара
│   ├── bridges.ts        # Система разводных мостов (Дворцовый, Троицкий и др.)
│   ├── transit.ts        # Трамваи (маршрут №3), Метеоры и катера
│   ├── weather.ts        # Погода онлайн (Open-Meteo) и пиксельные осадки
│   ├── flight.ts         # Симулятор полёта (физика, модель самолёта, управление)
│   ├── landmarks.ts      # Модели достопримечательностей центра СПб
│   ├── ui.ts             # Интерфейс (кнопки, ползунок времени, HUD полёта)
│   └── style.css         # Пиксельные ретро-стили UI
└── scripts/
    └── extract_osm.py    # Скрипт выгрузки зданий и рельсов из OpenStreetMap
```

## 🗺️ Расширение на весь город (OSM данные)

Чтобы выгрузить дополнительные кварталы Петербурга (Васильевский остров, Петроградскую сторону, Коломну и др.):

```bash
python3 scripts/extract_osm.py
```

Скрипт автоматически сохранит полигоны зданий, высоты и типы крыш в `public/data/spb_center.geojson`.
